# Galentine's Card 💖

A personalized interactive Galentine’s Day card built with **HTML, CSS, and JavaScript**.  
Celebrate your best friends with custom GIFs, messages, and a soft pink theme.

---

## Features

- **Personalized Messages:** Enter your name to see a custom message just for you.  
- **Custom GIFs:** Display your own GIFs for each friend.  
- **Responsive Design:** Works perfectly on desktop, tablet, and mobile devices.  
- **Interactive Button:** Click the "Click Me!" button to reveal your personalized message.  
- **Soft Pink Theme:** Stylish pink colors and background for a cheerful look.  
- **Scrollable Messages:** Long messages scroll without breaking the card layout.
